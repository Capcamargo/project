# GiftMatch Edge Functions

В Supabase проекта используются три Edge Functions. Все они развернуты в облачном проекте GiftMatch и работают с `verify_jwt = true`.

## 1. `giftmatch-recommendations`

Назначение:

- принимает данные формы подбора;
- проверяет авторизованного пользователя;
- применяет rate limit;
- создает запись в `gift_requests`;
- формирует рекомендации на основе `gift_presets`;
- сохраняет результаты в `gift_recommendations`.

Hardening:

- `verify_jwt = true`;
- лимит 10 подборок за 10 минут на пользователя;
- проверка обязательных полей;
- проверка длины пользовательского ввода;
- запись только с `user_id` текущего пользователя.

Исходник сохранен в:

- `functions/giftmatch-recommendations/index.ts`

## 2. `giftmatch-account`

Назначение:

- проверяет активную сессию пользователя;
- создает профиль, если его еще нет;
- возвращает профиль;
- возвращает последний запрос пользователя;
- возвращает сохраненные рекомендации пользователя.

Используется на странице:

- `cabinet.html`

Security:

- `verify_jwt = true`;
- данные возвращаются только для текущего пользователя;
- доступ к строкам дополнительно ограничен RLS.

## 3. `giftmatch-save-selection`

Назначение:

- принимает список recommendation ids;
- проверяет, что эти рекомендации принадлежат текущему пользователю;
- помечает их как сохраненные;
- записывает `saved_at`.

Используется в основном сценарии:

- после получения рекомендаций на `app.html`;
- перед отображением сохранений в кабинете.

Security:

- `verify_jwt = true`;
- сохраняются только рекомендации текущего пользователя;
- RLS дополнительно ограничивает доступ на уровне базы.

## Проверка после деплоя функций

1. Войти в аккаунт.
2. Создать подборку на главной странице.
3. Убедиться, что создалась запись в `gift_requests`.
4. Убедиться, что создались записи в `gift_recommendations`.
5. Нажать «Сохранить подборку».
6. Убедиться, что `is_saved = true` и заполнен `saved_at`.
7. Открыть кабинет.
8. Убедиться, что сохраненные рекомендации отображаются.
9. Сделать много запросов подряд и проверить, что rate limit срабатывает.

## Что показывать на экзамене

- список Edge Functions в Supabase Dashboard;
- включенный `verify_jwt`;
- таблицы `gift_requests` и `gift_recommendations` после тестового подбора;
- rate limit в `giftmatch-recommendations`;
- исходник `giftmatch-recommendations/index.ts` в GitHub.

## Ограничение

Полные исходники `giftmatch-account` и `giftmatch-save-selection` уже развернуты в Supabase. Если нужно полностью версионировать их в GitHub, их можно экспортировать из Supabase Dashboard или CLI и добавить в папки:

- `functions/giftmatch-account/index.ts`;
- `functions/giftmatch-save-selection/index.ts`.
