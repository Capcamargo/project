# GiftMatch MVP

Веб-версия сервиса персонализированного подбора подарков.

Публичный MVP: https://giftmatch-qqdu.onrender.com

## Что делает GiftMatch

GiftMatch помогает быстро подобрать подарок по поводу, бюджету и интересам получателя. Пользователь проходит короткий сценарий, получает объяснимые рекомендации, сохраняет подходящие варианты в кабинете и при достижении лимита бесплатного плана видит тарифный шаг.

## Supabase

В проекте используется Supabase:

- `profiles` — профили пользователей, тариф и статус оплаты;
- `gift_presets` — публичные пресеты подарков для каталога;
- `gift_requests` — пользовательские запросы на подбор;
- `gift_recommendations` — результаты рекомендаций и сохраненные подборки;
- Edge Functions — рекомендации, аккаунт и сохранение подборок;
- RLS — разделение пользовательских данных.

Подробности находятся в `supabase/README.md`, `supabase/schema.sql`, `supabase/queries.md` и `supabase/rls-notes.md`.

## Что уже умеет сайт

1. Показывать ценность сервиса на первом экране.
2. Показывать каталог готовых идей подарков.
3. Создавать пользовательский профиль через Supabase Auth.
4. Принимать параметры подбора подарка.
5. Формировать подборку с пояснениями.
6. Сохранять подборки в истории пользователя.
7. Ограничивать число сохранений на бесплатном плане.
8. Показывать paywall после достижения лимита.
9. Проводить учебный тестовый тарифный сценарий.
10. Показывать обновленный тариф в кабинете.

## Важное ограничение MVP

Платежный сценарий является учебной имитацией. Реальная интеграция с ЮKassa, CloudPayments или другим платежным провайдером не подключена. Для production-версии потребуется server-side webhook и проверка оплаты на стороне платежного провайдера.

## Что открывать

Для локального просмотра и дальнейшей доработки использовать `app.html`. Для публичной демонстрации использовать Render-ссылку.
